# 战役名 · 裁决参数

## 量级参考（不是史学结论）

下表只用来判断"自己填的数有没有差一个数量级"，各时代内部差异极大，不能直接照抄。
真正的依据应该是**这场战役的战场正面宽度与双方武器有效射程**。

| 时代 | `control_radius_km` | `encircle_radius_km` |
|---|---|---|
| 冷兵器会战（长平、坎尼） | 2—4 | 8—20 |
| 线膛枪 / 排队枪毙（19 世纪） | 1—3 | 5—15 |
| 一战堑壕 | 3—8 | 20—50 |
| 二战机械化 | 6—10 | 30—60 |
| 冷战后合成兵种 | 15—30 | 80—150 |

判断方法：**把「战场正面宽度」除以「在场单位数」**，如果算出的间距
远大于本单位本回合可机动距离，就很难通过当前的可接触检查；应核对初始距离、
时间跨度和地形系数。`contact_km`不参与该检查，修改它不会增加可接触单位。
近现代支援单位另有地面几何限制；具体参见抗美援朝资料说明。
