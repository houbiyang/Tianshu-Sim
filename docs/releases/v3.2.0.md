# GenTactix-DSH 3.2.0

本版将长征与抗日战争资料、可重放局部教学演习及完整场景介绍纳入 Linux 桌面包。

## 更新内容

- 双语 README 逐项介绍全部45个场景：长平之战1个、红军长征15个、抗日战争20个、抗美援朝9个；列出时间、作战背景、教学关注及史料链接。
- 新增长征、抗日战争的来源登记、部队说明、事件时间表、数量口径与待考事项；总览和子战斗分别建档，保留来源冲突与未知值。
- 分离开放推演与历史回放，修复“日／天”回合选项，持续检索所选场景的关键规则。
- 抗日战争20个条目各提供1份固定局部演习，覆盖迟滞、突围、攻坚、交通破袭、隐蔽存续、航空支援与停火接收7类规则。
- 模型生成命令，程序结算人员装备账、库存、时钟和目标；支持同一回合初态的只读命令对照及存档恢复。

## Linux 下载与更新

在 [v3.2.0 Release](https://github.com/snow-wind-001/Gentactix-DSH/releases/tag/v3.2.0) 下载：

| 文件 | 用途 |
| --- | --- |
| `GenTactix-DSH-3.2.0-amd64.deb` | Ubuntu 安装或升级，自动注册应用菜单与图标 |
| `GenTactix-DSH-3.2.0-x86_64.AppImage` | 赋予执行权限后双击运行；无 FUSE 时可使用解压运行方式 |
| `GenTactix-DSH-3.2.0-x64.tar.gz` | 解压后运行 `gentactix-dsh` |
| `SHA256SUMS-3.2.0.txt` | 三种安装包的 SHA-256 校验值 |

先在旧程序中保存或导出战局，退出旧实例后运行新版。桌面入口会复用已有健康后端，因此仅更换文件而不退出旧进程，不会加载新代码。模型设置与战局存储规则见[桌面使用说明](../桌面启动与配置.md)。

## 验证范围

- 本次隔离环境执行172项核心、SDK与后端回归，全部通过；前端类型检查及生产构建通过，`npm audit` 为0项漏洞。
- 编译后端验证45个场景、20个演习、模式约束、无模型初始化、导出导入、检查点与重启恢复；包内 DSH runtime 可执行文件版本为 `0.2.1-rc.2`。
- 实际 AppImage 在隔离 Xvfb 桌面启动，验证原生模型配置菜单、64k输出预算、窗口图标、场景选择、固定初态、地图、JSON下载、刷新恢复及桌面重启恢复；退出后自启后端关闭。未关闭 Electron 沙箱。
- Debian 包检查版本、菜单、三种尺寸图标及 `StartupWMClass`，核对新增数据与源码一致；便携归档逐文件比对构建目录。未在此次验收中执行系统级 Debian 安装。
- 20场真实模型验收沿用本版功能开发阶段的结果：74个提交回合、76条已核验DSH调用，保留2次真实超时及续验记录。本次打包检查没有重新运行这些模型回合。详见[逐场验收报告](../局部推演规则与逐场验收-2026-10-22.md)。

固定演习采用合成的6个编组、30分钟回合和最多4回合。它们不是完整历史战场复原；7场攻坚与2场航空类此前未达红方截止目标，参数平衡和历史标定仍待完成。长征与抗美援朝尚未接入固定局部演习。各场景不会自动继承战局，地形遮蔽、真实运输吞吐与完整通信模型尚未实现。

## English

Version 3.2.0 packages all 45 documented catalog entries, sourced Long March and WWII China materials, and 20 synthetic local exercises. Open simulation and historical replay have separate instructions. Local exercises use model-generated orders with deterministic ledgers, supply constraints, objectives, saved-state recovery and read-only order comparisons.

Linux amd64 `.deb`, AppImage and portable `.tar.gz` packages are provided with SHA-256 checksums. The release passed 172 regression tests, frontend type checking/build, zero-vulnerability npm audit, frozen-backend smoke tests, and an actual sandboxed AppImage startup/UI/restart check. Debian menu/icon metadata and portable archive contents were inspected; a system-wide Debian installation was not performed in this release check.

The earlier 20-scenario live acceptance covers 74 committed turns and 76 verified DSH runs; these calls were not rerun during packaging. Local exercises are synthetic teaching assumptions, not historically calibrated deployments. See the linked acceptance report for timeouts, unsuccessful objectives and remaining limits.
