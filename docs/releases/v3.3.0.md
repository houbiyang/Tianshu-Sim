# GenTactix-DSH 3.3.0

发布日期：2026-10-25

本版将战棋指挥与 DSH 原生单位 Agent 从源码功能纳入 Linux 桌面安装包。更新源码与更新已安装程序是两个步骤；旧 AppImage 不会因 `git pull` 自动包含新界面。

## 主要改进

- 点击单位军标打开行动菜单，移动时在地图选目的地；支持单位名单选择、敌方目标、持续移动和几何预览。
- 单位／全局自然语言先生成草稿，核对后确认入队；咨询保持只读，输入或态势变化会使旧草稿失效。
- 已确认命令在下一轮统一执行。版本冲突可恢复，丢失响应时保留幂等批次，避免重复推进。
- 按需启用独立的 DSH 原生单位 Agent，复用原生创建、恢复、观察工具、事件及取消；人工命令优先，不另建会话与调度框架。
- 完整记录各单位的公开决策依据、命令来源、实际位置、人员／补给差异及原生事件引用；缺失依据明确标注，不从历史战报补造真实 Agent 轨迹。
- 历史回放可创建独立开放分支；固定局部演习支持单单位只读命令对照，结果绑定单位和回合。
- 失能／退役任务终止并归档，受阻任务暂停；无坐标单位可保持未知位置待命。切换控制范围前预览并确认受影响的旧命令和 Agent。
- 启动页和工作台增加 JSON 文件导入，服务端预览、确认共用校验；内存和磁盘 ID 冲突均拒绝覆盖。原生 DSH 日志不包含在 JSON 中。
- Worker 的 Miniflare→Undici 链限定到修复版本；前端与 Worker 依赖审计均为 0。安装脚本使用宿主系统 GIO，避免 Conda 的 GIO 缺少 GVfs 支持导致桌面图标未被信任。

## 安装与本机更新

发布文件：

- `GenTactix-DSH-3.3.0-x86_64.AppImage`：双击启动。
- `GenTactix-DSH-3.3.0-amd64.deb`：Ubuntu 系统安装包。
- `GenTactix-DSH-3.3.0-x64.tar.gz`：解压后运行 `gentactix-dsh`。
- `SHA256SUMS-3.3.0.txt`：下载校验。

本机当前采用用户级 AppImage 安装，已通过 `tools/install_linux.py` 替换 `~/.local/share/GenTactix-DSH/GenTactix-DSH.AppImage`，刷新 Ubuntu 菜单、图标和已信任的桌面快捷方式。旧程序和数据保留了本机回滚副本。

切换前先保存检查点并关闭源码进程，再从实际菜单入口启动新 AppImage，确认 8700 端口运行的是包内冻结后端，OpenAPI 版本为 **3.3.0**。本机两个安装版对局的战局、回合、战报、轨迹及命令状态与切换前一致；模型密文、Vault 密钥和原存档内容及权限保持不变。源码目录中的旧对局未迁移或覆盖。

## 使用边界

普通开放场景目前核验 `hold/move`，其余损耗仍为模型估计；固定局部演习按现有教学规则结算额外动作。机动圈不表示道路通行或地形遮挡已验证。20 个局部演习采用合成编组，不能证明历史会战伤亡准确。长征和抗美援朝资料也不等于已实现全部专属规则或跨场景继承。

历史回放只读；要改令需新建开放分支。原生日志缺失会明确失败，需保留原日志或显式重建单位会话，导入 JSON 不会补造会话记忆。Windows、macOS 安装包尚未验收。
