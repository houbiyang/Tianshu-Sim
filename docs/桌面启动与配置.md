# 桌面启动与模型配置

开发维护单位：沈阳理工大学装备工程学院深度学习实验室。
基于 [pystrategylab/Gentactix](https://github.com/pystrategylab/Gentactix)，感谢原作者开源，保留 MIT 版权。

## Linux 运行

Ubuntu 推荐下载 `.deb`，双击交给系统安装器安装，或运行下方 `apt` 命令。安装时自动注册图标与应用菜单；按 Super 键搜索 **GenTactix** 即可打开，卸载时系统会移除菜单入口。安装需要系统管理员授权。

AppImage 是免安装版本，赋予执行权限后可以双击；也可解压 `tar.gz`，运行其中的 `gentactix-dsh`。包内包含 Python 后端、DSH runtime 与地图轮廓，无需安装 Conda。需要图形桌面与系统支持的 Electron 沙箱；不要通过关闭沙箱解决启动问题。

```bash
sudo apt install ./GenTactix-DSH-3.2.0-amd64.deb
# 或使用免安装版
chmod +x GenTactix-DSH-3.2.0-x86_64.AppImage
./GenTactix-DSH-3.2.0-x86_64.AppImage
# 无 FUSE 环境可使用 AppImage 的解压运行方式
APPIMAGE_EXTRACT_AND_RUN=1 ./GenTactix-DSH-3.2.0-x86_64.AppImage
```

启动后先显示中国及周边地图。选择战役，或通过问答生成想定；第二步确认推演目标、回合跨度与规则，再进入工作台。已保存战局可从启动页恢复。远程瓦片需要网络，离线仍有粗略海岸轮廓；轮廓不提供高程、国界或射界遮挡计算。

源码工作区也可以免 sudo 安装 AppImage 到当前用户目录，同时创建菜单入口和桌面图标：

```bash
python tools/install_linux.py release/GenTactix-DSH-3.2.0-x86_64.AppImage --project-root .
```

文件存放于 `$XDG_DATA_HOME/GenTactix-DSH`（默认 `~/.local/share/GenTactix-DSH`），菜单项为 `applications/gentactix-dsh.desktop`。此入口使用解压运行方式，兼容无 FUSE 环境。GNOME 若提示不可信启动器，右键选择「允许启动」。

用户级安装器使用图标绝对路径，并刷新可用的 GTK 图标缓存，避免旧缓存造成菜单或任务栏图标空白。已安装旧入口时，重新运行上述安装命令即可修复；不会清除战局或模型配置。

## 配置与加密

打开菜单「配置 → DSH · LLM配置」或按 `Ctrl+,`。可修改接口地址、模型ID、API Key、输出上限、上下文容量、超时，以及每个角色的输出预算、推理强度、运行步骤与工具次数。先保存，再测试当前连接。更换配置不清除已有战局；模型运行中暂不可修改。

vLLM 地址通常以 `/v1` 结尾，模型ID必须对应服务的 `served-model-name`。无鉴权服务可清除已有Key。DeepSeek 使用 `https://api.deepseek.com/v1` 和 `deepseek-flash`；兼容别名以官方服务为准。推理强度档位是否支持取决于服务。

全部客户端配置使用 Fernet 认证加密，保存为项目根目录 `.gentactix-llm.enc`，文件权限0600。密钥单独保存于 `$XDG_CONFIG_HOME/GenTactix-DSH/vault.key`，默认是 `~/.config/GenTactix-DSH/vault.key`。文本编辑器无法直接读出配置；同一用户取得密文与密钥后仍能解密。API不回显Key，浏览器不持久保存它。

源码版默认使用仓库根目录。独立包若能识别父目录中的源码仓库则使用该根目录，否则使用可执行文件所在目录；目录不可写时（例如 `.deb` 安装到 `/opt`），自动使用用户数据目录下的 `project/` 作为可写项目根目录。可用 `GENTACTIX_PROJECT_ROOT` 显式指定。高级路径覆盖为 `GENTACTIX_LLM_CONFIG` 与 `GENTACTIX_VAULT_KEY_FILE`。首次启动可使用 `GENTACTIX_LLM_*` 环境变量引导，保存后以加密配置为准。

迁移到另一台机器时需分别备份密文和密钥。丢失密钥无法恢复原配置，可在界面重新填写保存；不可读取的旧密文会保留为 `.enc.unreadable`。公开源码和安装包均不包含个人默认Key，当前机器的默认Key只写入本地密文。

## 源码构建

使用干净的 Python 3.10+ 虚拟环境，避免本机旧包污染打包依赖。

```bash
python3 -m venv .packaging-venv
.packaging-venv/bin/pip install -r requirements-desktop-build.txt
cd frontend
npm ci
cd ..
.packaging-venv/bin/python tools/build_linux.py
```

输出位于 `release/`。战局、轨迹和DSH工作目录在源码模式下属于项目缓存，独立桌面包使用用户数据目录；这些数据不随安装包发布。已经监听8700的健康后端会复用，源码变动后需先保存战局、重启后端，再核对 `/api/health` 的加载版本。

图标位于 `frontend/public/icons/gentactix.png`，由本项目使用 imagegen 生成；设计提示为深海军蓝底、象牙与金色罗盘G、少量决策节点、无文字的专业桌面应用图标。用户界面参考照片未打包或上传。
