# 抗美援朝地理参考锚点

核对日期：2026-10-21。数据文件为[`gentactix/korean_anchors.json`](../gentactix/korean_anchors.json)，含九场战役、28个去重参考点。每点保留原地名、来源链接、经纬度、类型、工作不确定范围；格网换算点另保留原格网与度分秒。坐标用于把场景放到正确地域，不能替代战时阵地测绘。

## 地名核对与精度

- **温井与云山旧城：** 温井参考为`40.11083,125.89694`（GeoNames现名Unsan、旧名Onjong）；云山旧城参考为`39.97278,125.80528`，两者相距约17公里。不能只按现代县名选点。
- **597.9高地：** Martin Markley表的`CT 659419`及`N38 19′8.43″ E127 27′56.91″`换算为`38.319008,127.465808`。
- **537.7高地北山：** 表的`CT 677426`换算参考为`38.325583,127.486264`。原纬度排印`19’32’10`按32.10秒读取，保留此解释而不冒充无歧义测量。
- **金城与金化：** 金城旧城参考使用GeoNames现名Kimhwa、别名Kumsong的点；不能据现代“金化”名称将三角形山南侧1952年金化旧城搬到该点。
- GeoNames城镇、山口、车站均为现存地名参考。城镇一般采用2公里工作不确定范围；Markley格网表未注明大地基准，采用约1公里范围。该范围是保守建模约定，不是来源提供的测绘精度或统计置信区间。地图按WGS84显示，未完成旧军图大地基准配准。

## 程序接入与约束

`anchors.collect_available_nodes(scenario, battle=selected)`复用裁决库全名与别名解析，显式选择优先。两套入口均传入当前选择。提示词发送真实坐标、来源与不确定范围，避免模型只看到地名后自行补坐标。

单位声明完全一致的`node_name`时，`geo.sanitize_init_units`才将朝鲜战争单位吸附到该点。仅在名称中出现“进攻597.9高地”不会自动部署到山顶；未声明的周边部署仍由模型给出并接受既有地理审计。别场战役的节点不会生效，陆上参考点不能让舰艇绕过海陆检查。

这并未实现对所有自由部署坐标的历史偏移检测，也没有新增阵地多边形、坑道、补给站、道路通行或DEM视线数据库。真实推理验收与剩余问题见[功能验收报告](功能验收报告-2026-10-21.md)。
