# 战棋指挥与DSH单位Agent本地验收

日期：2026-10-24。基线：v3.2.1（`a385a37`）。本次交付为本地源码及测试，未推送GitHub、未替换已安装程序。实施依据为[开发规划](战棋指挥与DSH智能体开发规划.md)。

## 已实现的闭环

点击军标或从名单选择单位，选择动作，在地图指定目的地或敌方目标，校验后加入队列，下一回合统一执行。预览包括直线距离、当轮预算、预计剩余距离；持续移动按每轮上限推进。Esc取消选点并恢复焦点。重叠军标先列出单位；无坐标及退役单位可在名单查看记录。

单位和全局自然语言复用DSH形成草稿，咨询继续走原问答接口。草稿不会自动下令；不明确的对象、未实现动作或缺失地图目标必须澄清。过期草稿不能覆盖新队列，编辑后的命令不能冒用原解释来源。控制方、导演模式及禁止主动射击由应用校验。

已确认命令高于模型规划。回合冻结版本及批次ID，重复提交不再次扣减。状态、队列、持续任务与回执共同写入检查点后再提交内存；失败与取消保留原战局。未提交的轨迹残留在重试时归档，既不覆盖已提交历史，也不另建WAL。退役、失能及规则版本变化有明确停止或暂停记录。

## DSH复用与证据

运行模式仍为 **Native + sdk-minimal，PTC关闭**。单位身份、权限和规则在应用层；会话、事件、工具、取消、恢复及模型预算使用现有DSH能力。

- Cordis插件通过原生 `ctx.agents.create/resume` 建立独立单位会话，不复制其他角色的对话种子。新会话首轮前尚无可恢复日志；首轮完成后才按原ID恢复。
- `unit_planning.py` 每次注入同一权威初态的观察及全局限制；Agent只提出自身候选，不能改人员、装备或库存账。
- 原生单位和模型分支共用事件订阅、取消及结束门控适配。真实调用验证了 `get_observation`、`Agent.cancel` 和重启恢复。
- 单位默认由批量规划处理；只对明确启用且未被人工接管的单位调用独立Agent。真实测试使用两个不同单位身份及各自事件引用。
- 恢复缺失日志会报错；用户可以关闭该单位Agent，或明确重建会话记忆。重建留痕，旧日志保留，不能冒称恢复成功。
- 本次真实请求保持用户配置的 **high / 65,536 token**；未通过降低思考强度换取通过。

完整决策取消6/16条限制，支持单位及回合筛选、分页、DSH事件核验。人工命令、批量规划、原生Agent、默认待命、失能和依据缺失分别标识。历史回放的模型重建不冒充史实命令；从回放建立的开放分支有独立ID和来源标注。单单位命令对照复用现有纯函数规则，不写回主战局。

## 使用与复验

```bash
python verify_all.py
npm --prefix frontend run typecheck
npm --prefix frontend run build
python tools/qa/command_live.py --live
```

Python环境需同时具备 `requirements.txt` 与 `requirements-dsh.txt` 的依赖，避免把SDK跳过误算成完整通过。浏览器步骤见[QA工具说明](../tools/qa/README.md)。证据位于 `.cache/qa/results.json`、`.cache/qa/commands-live/` 和 `.cache/qa/commands-browser/`；原始模型轨迹仅本地保留。

总回归现显式隔离会话、轨迹、角色索引、DSH目录和模型设置。早期回归生成在默认轨迹目录的测试产物已移到隔离目录保留，角色索引恢复原内容。最终核对原2273个文件内容及权限全部一致，保护目录没有额外测试文件，6个原对局保留。

## 适用范围

20个固定演习复用现有可计算动作、补给、战损和目标规则。普通开放场景目前只对手动待命/移动作位置履行核验，其余战果仍为模型估计；不支持的射击、补给或工事动作不会显示为确定性执行能力。

机动圈和预定线是几何估计，没有新增道路寻路、DEM视线、战争迷雾或历史战损标定。固定教学场景的通过不等于45个历史资料条目均经过真实战役级验收；原生Agent的公开理由也不保证战略最优。
