# GenTactix-DSH 3.1.1 发布验收

日期：2026-10-22。单位：**沈阳理工大学装备工程学院深度学习实验室**。
感谢 [pystrategylab/Gentactix](https://github.com/pystrategylab/Gentactix) 作者开源，继续保留 MIT 许可与原版权。

本轮按功能、异常恢复、持久化、浏览器与桌面边界、真实模型、构建产物六类进行发布验收。
测试环境为 Ubuntu 22.04.5 / x86_64。结论适用于当前实现的功能与下列已执行用例，不代表商业认证或任意规模下零缺陷。

## 发现并修复的问题

| 问题与触发条件 | 修复后的行为 |
|---|---|
| 畸形导入对象导致500，错误回合数可写入；损坏检查点可能进入界面 | 导入返回422、不创建战局；恢复时隔离不完整文件并保留原件 |
| 任意网页来源可跨域访问本地API | 拒绝外部Origin及非本机Host，保留本机网页与Electron文件页面 |
| 模型操作并发排队，用户可能意外执行多次推进 | 忙碌时立即409；健康、进度和取消仍可访问 |
| 创建战局与检查点共用临时文件可能并发写入 | 写入加锁，仍通过fsync与原子替换落盘 |
| 桌面导出依赖页面导航，会被Electron导航限制拦截 | 读取完整JSON后下载Blob；下载与原始导出逐字段一致 |
| 问答失败仍留下未提交消息并丢失输入 | 撤回临时消息、恢复输入，支持再次发送 |
| 后端启动较慢时配置窗口停留在错误状态 | 每次打开重新加载配置，错误说明反映实际读取失败 |
| 真实Qwen问答消耗完2048与8192 token仍未给出正文 | 默认问答8192；问答、复盘、因果解读默认low推理强度；显式配置仍优先，截断输出继续拒收 |
| 重启后反事实报“fork parent is not live” | 精确恢复原父会话后创建分支；历史缺失时拒绝，不能新建空会话冒充 |
| 桌面将其他服务的200响应误认为后端 | 验证health服务身份，探测有超时；冲突时显示明确错误 |
| Electron与Worker工具链存在高风险依赖公告 | Electron升级45.0.0；Wrangler升级4.151.3并同步类型包；构建排除宿主ROS的PYTHONPATH |

## 真实DSH/vLLM结果

使用现有加密配置连接Qwen，未打桩模型。独立上甘岭局部教学想定为双方各两个代表单位。

- 想定生成11.69秒，初始化32.70秒，两轮分别58.03、54.56秒。
- 时钟严格为04:00 → 04:15 → 04:30，累计1800秒，四个单位保留。
- 轨迹证据包含3次`evaluate_action`与2次`get_observation`原生工具调用。
- 修复后的问答9.26秒、复盘11.39秒、归因19.10秒；轨迹持久化核验通过。
- 重启后成对原生分支93.74秒，两臂均通过时间、位移与计数校验；几何试算及模型分支均不改写主战局。
- 独立真实取消测试获原生确认，0.851秒返回409，态势、历史、复盘不变，进度清除。

前两次问答预算失败与首次恢复分支失败均保留在本地证据中，未计为通过。恢复后继续测试，避免为验证问答反复新建战局。8700原有战局在检查点后重启，世界状态、回合数、历史、轨迹、问答与复盘逐项一致。

## 发布与边界

发布Linux AppImage、便携tar.gz及SHA256SUMS；包内包含独立Python后端，未包含私有Key、配置密文或解密密钥。发布前核对归档可执行权限、配置排除与密钥扫描，上传后核对GitHub资产摘要。

最终便携包解压后实际启动其内置后端：10项战役可读，真实DSH连接通过，导入/导出战局一致。归档含354项，检查了约773MB展开文件；AppImage最终版本额外验证旧格式非法导入返回422，确认运行的是修复后的二进制。

依赖审计：Worker为0；前端运行依赖为0，高风险/严重告警为0。桌面构建工具仍有8个中风险依赖节点，源于`@electron/get@3`经`global-agent/roarr`引入的`sprintf-js`精度拒绝服务公告，审计当时无原版本修复；它们不进入renderer运行依赖。未通过强制降级或跨主版本override掩盖告警。Electron版本依据[官方45.0.0发行说明](https://github.com/electron/electron/releases/tag/v45.0.0)。

未覆盖Windows/macOS、多机硬件兼容矩阵、九场战役真实多日推演、超大单位规模负载；未连接真实DeepSeek官方服务做同等验收。地形展示不等于DEM视线/弹道计算，模型归因不等于历史因果证明。当前本机服务保留Electron所需的`null` Origin，不能把这项来源限制当作多用户身份认证。

复现入口见[QA工具说明](../tools/qa/README.md)。本轮私有日志与原始结果保存在`.cache/qa/release-3.1.1/`，不上传；公开文档只记录范围、结论与可复现命令。
