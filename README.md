# GenTactix-DSH

**简体中文** | [English](README.en.md)

历史战役推演与决策复盘工作台。基于 Vue 3、Electron、FastAPI 和 DeepSeek Harness（DSH），将战役资料、地图态势、逐回合推演与决策轨迹放在同一界面中，面向历史教学、想定讨论和软件研究。

![启动与战役选择](docs/screenshots/launch.png)

## 主要功能

- **战役选择与想定创建**：启动后显示中国及周边地图；当前源码资料库包含长平之战、九场抗美援朝战役、15个红军长征场景和20个抗日战争场景，也可通过问答生成想定。
- **地图与态势**：展示双方单位、移动轨迹及状态；有对应数据时可显示地形要素、射界、远程火力范围、补给节点与路线、人员和装备损失。缺失数据保留为未知。
- **可重放局部教学**：20个抗日战争场景可选固定初态，按7类教学规则结算命令、人员装备账、库存与目标；支持同一初态的命令对照。合成编组与系数未作史实标定，详见[设计与边界](docs/可重放推演设计.md)。
- **逐回合推演**：设置回合时长，由程序维护时钟；保留单位名单与状态，并检查异常坐标、数值及单位遗漏。可开启几何裁决，约束位移、补给连通与包围判定。
- **DSH 智能体与插件**：采用 Native 工具模式，支持持久角色会话、只读领域工具、运行事件观测、预算控制和在途取消；保留应用层 JSON 工具兼容模式。
- **决策复盘**：查看战报、关键决策与转折点，结合轨迹进行归因分析；支持几何反事实与成对模型分支，分支结果不直接覆盖主战局。
- **资料与存档**：本地史料检索、战役裁决参数、会话检查点、恢复以及 JSON 导入导出。
- **模型配置**：菜单中编辑 vLLM / OpenAI 兼容接口或 DeepSeek 接口、模型、密钥、超时和角色预算；配置加密保存。

新资料的编辑入口：[红军长征](data/long_march/README.md)、[抗日战争](data/anti_japanese_war/README.md)。资料卡保留来源、争议和未知值；新增几何参数为教学估计，已安装的旧版本需重新构建才会包含这些资料。

## 战役与场景目录

当前源码目录共 **45个条目**：长平之战1个、红军长征15个、抗日战争20个、抗美援朝9个。下表名称链接到对应史料卡，卡内提供部队、过程、来源及数据争议；时间沿用资料目录的记载精度。总览、阶段与子战斗分别建档，不能把它们的兵力或战果重复相加。

| 使用方式 | 适合的任务 | 当前支持 |
| --- | --- | --- |
| 开放推演 | 围绕历史背景提出不同决策，观察模型生成的后续态势 | 全部45个目录条目；初态由模型生成，可选几何裁决 |
| 历史回放 | 结合来源讲解战役过程与关键决策 | 全部45个目录条目；不强制按历史伤亡总数扣减单位 |
| 固定局部教学 | 从相同初态比较命令，检查账目、补给和程序目标 | 抗日战争20个条目各有1份合成局部演习；仅开放推演模式可选 |

固定局部演习统一采用6个教学编组、30分钟回合、最多4回合，使用7类规则。其人员、装备、局部位置和系数是教学假设，不能代替整场历史会战的复原。下表“局部规则”指该演习的实际规则类别，其余“教学关注”供讨论与选题，不代表所有机制均已实现。会战之间目前不会自动继承态势。

### 自定义想定

启动页可通过问答创建想定，也可关联已有资料卡。独立想定没有预先考证的专属档案；需自行补充部队、初态、地理与目标，并核对模型生成内容。增加目录条目的方法见[史料格式](corpus/README.md)和[裁决参数说明](adjudication/README.md)。

## 安装与启动

当前桌面版：[v3.2.1](https://github.com/snow-wind-001/Gentactix-DSH/releases/tag/v3.2.1)。DeepSeek 接口兼容修复、DSH 运行时及安装验收见[版本说明](docs/releases/v3.2.1.md)。

从 [Releases](https://github.com/snow-wind-001/Gentactix-DSH/releases) 下载 Linux x86_64 安装包。包内包含后端和 DSH runtime，无需另装 Python 或 Conda；运行推演仍需可用的模型服务。

| 格式 | 使用方式 |
| --- | --- |
| Ubuntu `.deb` | 使用系统安装器安装，或执行 `sudo apt install ./GenTactix-DSH-3.2.1-amd64.deb`；安装后在应用菜单搜索 **GenTactix** |
| `.AppImage` | 赋予执行权限后双击运行；无 FUSE 时可加 `APPIMAGE_EXTRACT_AND_RUN=1` 启动 |
| `.tar.gz` | 解压后运行其中的 `gentactix-dsh` |

在源码工作区中，也可为 AppImage 安装当前用户的菜单项和桌面图标：

```bash
python3 tools/install_linux.py release/GenTactix-DSH-3.2.1-x86_64.AppImage --project-root .
```

详细步骤、构建方法及配置迁移见[桌面使用说明](docs/桌面启动与配置.md)。当前提供 Linux 包，尚未验证 Windows 或 macOS 安装包。

## 开始一次推演

1. 打开菜单 **配置 → DSH · LLM配置**（`Ctrl+,`），填写接口与模型，保存并测试连接。vLLM 的模型 ID 应与服务端的 `served-model-name` 一致。
2. 在启动页选择战役，或通过问答创建想定；选择开放推演或历史回放，确认回合时长、史料检索与裁决选项。抗日战争资料可选固定局部教学初态；初始化不调用模型。
3. 在工作台推进回合、观察地图与战报，也可提问、复盘或比较反事实分支。
4. 导出战局 JSON，或从启动页恢复已保存的会话。

配置通过 Fernet 认证加密保存为项目目录中的 `.gentactix-llm.enc`，解密密钥单独存于用户配置目录。安装目录不可写时，桌面程序使用用户数据目录下的可写项目目录。公开仓库与安装包不含个人 API Key；同一用户同时取得密文与密钥后仍可解密。

## 源码运行

使用 Python 3.10+、Node.js 22 和图形桌面。在仓库根目录执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dsh.txt
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8700
```

另开终端启动 Electron 开发界面：

```bash
cd frontend
npm ci
npm run dev
```

原有 Streamlit 界面保留于 `app.py`，可通过 `.venv/bin/streamlit run app.py` 启动；其功能与桌面版不完全相同。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `frontend/` | Vue 界面、地图和 Electron 桌面入口 |
| `backend/` | FastAPI 接口、会话管理与分析服务 |
| `gentactix/` | 推演、状态守恒、时钟、地理、史料检索和裁决逻辑 |
| `plugins/dsh-gentactix/` | DSH 原生领域工具、运行观测与控制插件 |
| `corpus/`、`adjudication/` | 史料卡片与各战役裁决参数 |
| `verify_*.py`、`tools/` | 回归检查、真实模型测试和打包安装工具 |

完整测试范围见 [TESTING.md](TESTING.md)。[50步审计](docs/50步推演与输出审计-2026-10-22.md)保留真实运行中的失败和语义问题；[3.1.3 修复记录](docs/补给射界与战报一致性修复-2026-10-22.md)说明补给、射界与战报校验，并记录历史回放、4步真实续推及复盘复测。[3.1.4 修复记录](docs/空正文恢复修复-2026-10-22.md)说明正常结束但无正文时的一次自动恢复、取消与状态保留，以及139项回归和真实会话副本续推验证。这不代表所有战役与模型行为均已验证。

开放推演允许偏离历史结果；历史回放用于史料讲解，不作为反事实验收。程序提供教学推演与解释辅助。模型生成的伤亡、士气和归因不是经过验证的战斗效能或因果结论；HP 也不等于人员数量。几何裁决默认关闭，不能替代弹道、地形遮蔽或后勤吞吐模型。地图射界为示意图层，离线底图为粗略轮廓，在线瓦片需要网络。DSH 使用方式及反事实边界见[架构说明](docs/因果分析与DSH插件架构.md)。
