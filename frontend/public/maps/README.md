# Offline map fallback

`land-110m.geojson` is Natural Earth's 1:110m physical land dataset, downloaded from
[natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson).
Natural Earth data is [public domain](https://www.naturalearthdata.com/about/terms-of-use/).
It provides coarse coastlines only, without administrative borders or tactical elevation.
The initial view is centered on China (35.8°N, 104°E); online basemaps retain their own attribution.
