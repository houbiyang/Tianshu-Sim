# 史料语料库

把 `.md` 文件放进这个目录，应用会自动索引（无需改名、无需注册、无需重启）。
地图页右上「📚 史料库」显示当前索引了多少个文件、多少个片段。

## 会被索引的文件

- 本目录及子目录下的所有 `.md`
- 文件名不以 `_` 或 `.` 开头

## 不会被索引

- `README.md`（就是本文件，防止把格式说明当成史料检索出来）
- 以 `_` 或 `.` 开头的文件（临时草稿可以这样命名）

## 文件格式

只有一个硬约定：**用二级标题 `##` 切分片段**，每个 `##` 就是一个可被独立检索、独立引用的单元。
一级标题 `#` 作为来源名显示。

```markdown
# 战役名称（会作为来源名，如「长平之战」）

## 战役定位
这里写时间、地点、交战方、出处。

## 兵力与伤亡
这里写数字。**凡是史料没给的数字，请明确写「史料未载」。**

## 关键时间线
按顺序写可考节点。
```

片段越短越聚焦，检索越准。一个 `##` 建议控制在 200—600 字。

## 裁决参数已迁出（重要）

**本目录不再放裁决参数。** 一场战役的几何尺度（多近算接触、能封锁多宽、包围圈多深）
现在放在 `adjudication/<战役名>.md`，与史料彻底分开：

- 史料要能引用出处，尺度是一组可解释的估计值，混在一起容易被误读成"史书记载"。
- 一场战役一个文件，加新战役不必动已有战役，也不会互相覆盖。

旧写法（`corpus/*.md` 开头用 `---` 包一段 `contact_km:` 之类）**仍然兼容**，
但优先级低于 `adjudication/` 里的同名文件；两处都写时以裁决库那份为准。

详见 `adjudication/README.md`。


## 三条写作纪律

1. **有出处**。写清引自哪本书、哪一篇。没有出处的数字，标注「后世估算」。
2. **区分「史料记载」与「学界争议」**。例如长平「四十万」既是《史记》原文，也是有争议的数字，两者都要写，否则模型会把争议数字当成确证使用。
3. **别写推演结论**。语料是事实，不是战术建议；战术判断交给模型。

## 检索是怎么工作的

- 纯本地 BM25（词频—逆文档频率），**不联网、不调用任何 API、不产生费用、不需要 Key**。
- 中文按字符二元组切词，英文与数字按词切。没有分词词典，所以新出现的人名地名也不会失配。
- 索引按文件修改时间自动失效重建。改完文件，下一次推演就生效。
- 语料为空或检索零命中时，界面会明确提示「本次仍为模型自由发挥」，**不会静默降级**。

## 建议的组织方式

一场战役一个文件，文件名用战役名。跨战役的通用资料（如某朝代军制、某类武器的射程考据）单独建文件，检索时会被自动带出。

也可以按来源建文件，例如 `史记-白起王翦列传.md`，一个 `##` 对应一段原文摘录 + 白话说明。

## 抗美援朝九次战役

新增九份以 `抗美援朝-` 开头的档案，与裁决库同名配对，另有子目录内的兵种与统计口径说明。
完整索引及资料修订见 [抗美援朝资料说明](../docs/抗美援朝资料说明.md)。
命中完整名或裁决文件中的 `aliases` 时，检索在排名前排除其他抗美援朝战役档案，
保留共通资料，避免把相邻战役的伤亡总量注入当前场景；智能体检索工具沿用本局范围。
每份资料明确报告方、统计范围与出处，不能将异口径数据组成区间或求中值。

## 红军长征系列

15份`红军长征-名称-时间.md`与裁决库配对，共同规则在`红军长征/`子目录。
编辑源、时间表、统计口径及史料登记见[长征资料入口](../data/long_march/README.md)。
选定战役后只检索本卡及本系列共同资料，抗美援朝与长征档案互不混入。
本系列同时含教学假设和待考项，它们均单独标注，不得提升为史实或自动事件。

## 抗日战争系列

20份`抗日战争-名称-时间.md`与裁决库配对，共同资料在`抗日战争/`子目录。
[编辑入口](../data/anti_japanese_war/README.md)提供来源登记、阶段与战场矩阵、部队、事件、统计范围及待考表。
三次长沙分别建档；会战总览与子战斗的战果不得重复累加。检索按所选卡片及本系列共同资料限定范围。
1937—1945年选题不等于全部抗战名录；未知数、来源冲突和现代地名参考均明确标注。
