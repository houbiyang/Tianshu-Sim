# 抗日战争系列：资料与编辑入口

本包按“战略阶段 × 战场空间 × 局部攻防态势”组织1937—1945年全民族抗战选题。共20个场景，覆盖用户列出的主要方向，并补入缅北滇西反攻；不是十四年抗战或22次会战的完整名录。1931—1936年、南京、随枣、枣宜、常德等战场仍需另行建档。

## 场景与文件

[场景索引及阶段矩阵](INDEX.md)链接全部史料卡和裁决参数。三次长沙分别建档；平型关、台儿庄、万家岭、衡阳、车桥用`parent_id`关联所属会战或阶段，统计不得重复相加。

## 编辑与生成

先修改JSON主编辑源或地名参考，再在项目根目录运行：

```bash
python tools/render_anti_japanese_war.py
python tools/render_anti_japanese_war.py --check
python verify_anti_japanese_war.py
```

生成器更新`corpus/抗日战争-*.md`、`adjudication/抗日战争-*.md`、索引和五份CSV。直接编辑生成文件会被覆盖。每条部队、事件、数字必须引用登记来源，保留`scope`和`source_locator`；新增来源不能只挂在文末。

`published_account`表示公开记载，`source_conflict`表示来源冲突，`unverified`表示未核得，`teaching_window`表示教学设定。时间精度与证据等级分别记录：新闻中的“1时50分”不等于查验原始电报。`variant_group`用于标记日期异文，不会自动择一或执行。

数量未知用`null`，不得填0、套满编人数或从敌方伤亡反推。阵亡、伤亡、失踪、毙伤俘和综合兵力损失不可混加；城市、团数、公里与人数也不可混算。来源相互冲突时保留原口径，不用均值抹平。详见[核查报告](../../docs/抗日战争资料核查与接入-2026-10-22.md)。

## 在软件中使用

现有战役目录会发现20个带时间的完整名称；常用简称可解析到相应档案。启用史料检索后，初始化优先提供范围、部队与争议，后续检索限定当前卡片及本系列共同资料。矩阵是资料分类，当前前端没有新增矩阵视图。

先选一个具体日期和局部地域再初始化。会战累计投入不是同日在场兵力，总览卡不能把几个月、数百公里的行动压成同一张战术态势。目录的回合跨度是建议，不是已经校验过的历史时钟。

28处坐标均为现代聚落参考，不能自动视为乔沟伏击点、昆仑关山口、芷江机场或万家岭阵地。真实射界、历史河道、道路和火炮配置仍须补证。所有几何参数为`teaching_estimate`，尚未通过史实战果校准。

本批补全资料、目录、检索、年代提示与打包资源清单；未新增铁路修复、地下组织存续、空中遮断、群众支持度或战役继承算法。因果解释与反事实比较属于教学假设，不能把一次模型输出当作已识别因果。没有提供完整战局存档，也未运行真实模型长测。已安装的桌面包需重新构建才包含新资料。
